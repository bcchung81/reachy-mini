## 3. 수준별 교육자료 `/handout?level=…`

- 큐시트(검수한 고정 대본)의 **그 수준 도슨트 설명**과 사회자의 턴 질문을 섹션별로 옮긴 인쇄용 읽기 자료.
  LLM 생성 없음 — 사실은 조사 파일로 검증된 것만 나간다. 수준을 바꾸는 링크와 인쇄 버튼.
- 브리프·금지 규칙·`topic` 은 싣지 않는다(내부 지시문). 받아치기(`mc_after`)도 뺀다("다음이라고 말해 주세요" 류 안내).
- 기본 수준은 지금 감독의 수준. 조정실 헤더에서 [관람객 화면]·[교육자료] 를 새 탭으로 연다.

## 4. 재검증

- 가짜 로봇 두 대 + 진짜 감독·LLM·TTS 로 한 공연을 돌리며 보조 화면을 브라우저로 확인(자막·질문 안내·단독).
- 테스트: 보조 소켓이 경고·이력을 흘리지 않는다, 명령을 받지 않는다, 스냅샷 허용 칸만, 교육자료가 HTML 을 이스케이프하고
  수준별 설명을 싣는다.
