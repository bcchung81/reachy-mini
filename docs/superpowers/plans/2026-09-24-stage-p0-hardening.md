2026-09-24. 선행: `2026-09-22-podcast-turns-qa.md`(고정 대본 전환, 커밋 c78363d).
진행 방식(사용자 지시): **TDD 없이 바로 구현**, 구현 뒤 회귀 테스트로 박제, 서브에이전트 없이 한 세션에서.

**범위: 전부 PC 쪽(감독·데이터·문서·스크립트). 로봇 재배포 없음.** 로봇 앱은 이미

| # | 문제 | 근거 |

## 결정

| 항목 | 결정 |
|---|---|
| 중단 | `TurnMachine.abort()` 가 양쪽 마이크를 닫는다. 불변식: **마이크는 LISTENING 의 리스너만 열린다** |
| 운영자 조작 기록 | 콘솔·대시보드 명령을 터미널 로그(`start-director.log`)에 `[운영]` 한 줄로 남긴다 |
| 잡음 게이트 | 감독 `on_heard` 에서(재배포 불필요). 한글 음절 2개 미만·한글/라틴 밖 문자·짧은 단위 반복이면 **질문으로 보지 않고 경고**. 침묵 기한은 그대로 흐른다(잡음은 관람객이 말한 게 아니다). 진행어("다음")는 먼저 통과 |
| 듣는 쪽 반응 | `listener_emotion` 을 도슨트 설명 중 사회자(듣는 로봇)에게 `react` 로. **상대 발화 추정 길이의 40% 지점**(`speaking_started` 기준, `tick` 이 보낸다). caps 에 `react` 가 있을 때만, 1인 모드에서는 안 보낸다 |
| 듣는 로봇 시선 | 상대가 말을 시작할 때 듣는 로봇에게 `gaze partner`. caps 에 `gaze` 가 있을 때만, 1인 모드 제외 |
| caps 경고 | hello 때 `emotion`·`react`·`gaze` 중 빠진 것을 한 줄로 경고(재배포 필요) |
| 관람객 경로 감정 | 확인 멘트 3종 `기쁨·궁금·끄덕`, 재질문 `궁금`, 관람객 답 `설명` |
| 관람객 답 분량 | `levels.yaml` 의 `min/max_*` 를 **관람객 답 분량**으로 재정의(모든 수준 2~3문장, 초등 50~100·중고등 60~120·일반 70~140·전문가 90~180자). 도슨트 해설은 고정 대본이라 이 값을 쓰는 생성은 관람객 답뿐이다 |
| 프롬프트 | 도슨트 페르소나를 "관람객 질문에 답하는 역할" 로. 분량 지시에 "첫 문장에서 바로 답", "분량을 채우려고 지어내지 않는다". `_COMMON` 에 구어체 문장. 생성 직후 글말 어미면 경고(고치지 않는다) |
| 글말 판정 | `stage/speech_text.py::written_endings` 하나를 데이터 테스트와 생성 경고가 같이 쓴다 |
| 사실 원장 | 정본은 `data/cues-research/*.yaml`. `prompt_exhibit.md` 는 정정 반영 + 회귀 테스트. `docs/exhibit-guide.md` 는 머리에 원장 이전 안내, 틀린 줄은 취소선 |
| 손들기 진단 스크립트 | `probe_hand_raise.py` 로 이름을 바꾸고 `pytest.ini` 로 `testpaths = tests` |

## 작업 순서

1. 중단 시 마이크 닫기 + `[운영]` 기록 + IDLE 경고 문구 정정(`발화 중(idle)` → `듣는 중이 아닐 때`)
2. `stage/cues.py::noise_reason` + `Director.on_heard` 게이트
3. 감독: 듣는 로봇 시선·`react` 예약·caps 경고·관람객 경로 감정
4. 관람객 답: `levels.yaml`·`prompts.py`·`personas/docent.md`·`speech_text.written_endings`·`build_generate` 경고
5. 데이터 테스트(글말·기호·단위·턴 분량)
6. `prompt_exhibit.md`·`exhibit-guide.md` 정정 + 회귀 테스트
7. 진단 스크립트 이름·`pytest.ini`
8. 기존 테스트 갱신, 새 동작 회귀 테스트, `docs/lessons.md` 항목, `pytest` 전체

## 범위 밖

로봇 재배포가 필요한 것(질문 창의 VAD 온셋 신호, 대기 모션 집합), TTS 사전 합성 캐시, 공연 끝 처리,
받아치기 반복 줄이기, 코스·보조 화면 — 점검 보고의 P1·P2 로 따로 간다.
