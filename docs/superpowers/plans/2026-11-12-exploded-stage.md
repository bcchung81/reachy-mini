## 가져온 기술(소재 빼고 한 문장)

"부품 표 하나(부모·조립 위치·분해 벡터·순서·지연·회전·설명선 기준점·라벨)가 장면을 정하고, 장면 그래프가 표의 부모 관계를 따라
자식이 부모와 함께 분해되며, 바깥 부품이 앞장서는 순서 곡선(시작 = T + 0.55·sin(π/2·order/max) + delay, 길이 ∝ √dist, back.out)으로
한 동작처럼 풀렸다가 거꾸로(back.in) 재조립된다. 설명선은 3D 기준점(축 위 높이 + 반지름을 카메라 옆·앞으로)을 매 프레임 화면에 투영하고,
라벨 높이를 가중 등위 회귀(PAVA)로 정렬해 겹치지 않고, 지시선(기준점 → 버스 → 대각선 → 라벨)이 엇갈리지 않게 한다. 강조 부품만
역방향 껍질 외곽선."

가져오지 않은 것: 손전등·남색 스튜디오·크림 몸통·호박색 강조·9:16·라벨을 캔버스에 굽기·빛 원뿔·먼지. 장면은 대본에서 새로 지었다.

## 큐별 "무엇을 분해하나" — 대본(전문가)으로 확정

라벨 글은 **그 큐 대사 + 검증된 카드(전문가 수준의 headline·items·remember·visual)** 의 낱말에서만 쓴다(빌더가 대조해 어긋나면 멈추고,
`?check=1` 이 같은 대조를 브라우저에서 다시 해 `body[data-warn]` 에 적는다). §7.4 초안의 "안테나·송신기·전건"은 전문가 대사에 그 낱말이
없어서 **라벨로 쓰지 않는다** — 모양으로만 그리고 라벨은 대사의 말(모스 부호·폴듀…)로 단다.

## 구조

```
scripts/handout_exploded/
  build.py      HUD 검증 카드(l4 전문가) + 캐시 음성(전문가 문장, 큐시트 위치로 줄 세움) + 부품 표 대조 → docs/design/exploded-stage.html
  tables.yaml   큐마다 부품 표 하나(데이터만) — 부모·rest·dir·dist·order·delay·spin·tilt·phi·over·anchor·side·label·sub·say·leave
  scenes.js     큐마다 부품 모양(코드로 만든 형상만 — 시각·글자 없음). 표의 shape 이름이 여기 함수를 가리킨다
  parts.js      공통 형상 도구(필렛 단면 → 선반 회전체, 둥근 상자, 껍질 외곽선용 매끈한 법선)·재질
  layout.js     설명선 배치(가중 PAVA) — 순수 함수, 노드로 단위 시험
  template.html 엔진(three 장면 그래프·분해·투영·DOM 라벨·지시선 캔버스·강조·재조립·점등·재생 UI)
  vendor/       three 0.186.1(npm) 원본 그대로 + LICENSE + MANIFEST.json(출처·해시)
```

- **three 내장**: 0.186.1 은 ESM 전용이다(`build/three.cjs` 는 `require(esm)` 껍데기, min 빌드 없음). 빌더가 원본 파일을 고치지 않고
  `<script type="importmap">` 에 **data: URL**(base64)로 싣는다. 바꾸는 것은 `three.module.js` 의 상대 경로 `'./three.core.js'` 한 곳을
  맨 이름 `'three/core'` 로 바꾸는 것뿐이다(data: URL 모듈에서는 상대 경로가 풀리지 않는다). file:// · 헤드리스 SwiftShader WebGL2 에서
  `REVISION 186` 로드 확인(스크래치 시험 페이지). 고친 뒤에도 남은 상대 import 가 있으면 빌더가 멈춘다.
- **음성**: 종이 무대 빌더와 같은 규칙 — 캐시(`TTS_CACHE_DIR`, 기본 `cache-elevenlabs`) 문장을 큐시트 글 안의 위치로 줄 세우고, 이어 붙인
  글이 큐시트와 다르면 멈춘다(`docs/lessons.md` "색인 순서는 말하는 순서가 아니다"). 전문가 = `levels` 에 `전문가`.
- **시각**: 그림은 t 의 순수 함수(직전 프레임 상태 없음). 대사 시각은 `sc.w(낱말)` — 문장 안 글자 위치 비례(종이 무대와 같은 함수).
  `?cue=02&t=40` 으로 한 순간을 멈춰 본다.
- **화면**(1600×900 무대, 창에 맞춰 축소·확대): 가운데 x 610~990 에 분해 기둥(카메라 거리·렌즈 이동은 분해 상태의 경계 상자를
  투영해 자동으로 맞춘다), 설명선 열 왼쪽(오른쪽 끝 x 520)·오른쪽(왼쪽 끝 x 1080), 사회자(왼쪽 끝)·도슨트(오른쪽 끝) 아이콘·말풍선은
  그 바깥 고정 구역, 위에 제목·헤드라인, 아래에 지금 말하는 포인트 카드 → '기억해 두기'. 색: 밝은 HUD 바탕(`--bg #F3F7FA`)과 무채
  재질, **강조는 HUD `--sig #0B7FB5` 하나**(외곽선·강조 라벨·점등).
- **라벨은 DOM**(`textContent`), 지시선·기준점·전파 고리만 2D 캔버스(글자 없음). 라벨 열 배정은 표의 `side`(L/R) — 화면 위치로 정하지
  않아 열이 바뀌며 튀지 않는다. 번호는 처음 언급되는 순서.

## 성능 메모

데모 수치(프레임 517 ms)는 헤드리스 CPU 래스터다. 여기서는 그림자 1개(VSM 512), 반사는 금속·유리에만(PMREM), 무광 면은
구면 조화 9계수 LightProbe 로만 채운다(데모의 비용 절감 그대로). 헤드리스 SwiftShader 와 실제 GPU 에서 프레임 시간을 재서 아래
진행 기록에 적는다. **전시장 PC 실측은 남은 일.**

로봇 2대가 말하고 화면은 따라간다(`briefs/LIVE-contract.md`).

  말풍선·낱말 시각(`wordTime`)은 이 시계만 본다. 로봇·말풍선은 `people()` 로 떼어 매 프레임 갱신(장면이 멈춰도 말하는 로봇은 까딱인다).
- **발화 표** — 데이터의 `utt[{role, turn: open|ask<i>|docent<i>|after, t0, t1, s:[{x,t0,t1}]}]`, 종이 무대와 같은 계산(`LEAD 0.9 ·
  GAP_SENT 0.16 · GAP_UTT 0.5`, 시험으로 고정).
- **`?live`** — 오디오를 만들지 않는다(`audios = []`), 재생·탐색 컨트롤 숨김, `scripts/handout_live/live_follow.js` 를 빌더가 모듈 스크립트
  **앞의 일반 스크립트**로 인라인(전역 `LiveFollow`). 모듈이 없으면 빌드가 경고하고, 페이지는 `?live` 에서 "공연 모드 모듈 없음" 배지와
  WARN 을 낸다(조용히 멈춘 화면 금지). 큐를 모르면(-1) 01 조립 상태로 대기.
- **질문 흐름(`phase()==='qa'`)** — 장면을 그 큐의 마지막 대본 시각에 멈추고 말풍선을 비운다(생성 답 글 없음). 말하는 로봇만 까딱인다.

1. **YAML 흐름 매핑 `{…}` 안의 쉼표는 값을 자른다 — 잘린 값은 낱말 대조를 통과한다**
   - 증상: 02 수신 측 라벨 설명 줄이 화면에 "약 3" 으로만 나왔다. 빌더의 낱말 대조(대사·카드에 있는 낱말만)는 통과했다.
   - 원인: 부품 표 행을 `{…, sub: 약 3,500km (2,200마일) · …, say: […]}` 로 썼는데, 흐름 문맥에서 쉼표는 항목 구분자라 `sub` 는 "약 3",
     나머지는 `500km (2`·`200마일) · 지금도 논쟁거리` 라는 **새 키**가 됐다. "약"·"3" 은 대사에 있으니 대조가 잡지 못했다.
   - 규칙: 흐름 매핑에 쉼표가 든 글(숫자 3,500km)은 반드시 따옴표. 표 행에 올 수 있는 키를 정해 두고 모르는 키면 멈춘다(잘린 값은
     내용 대조로 못 잡는다 — 모양으로 잡는다).
   - 박제: `tests/test_handout_exploded.py::test_흐름_매핑의_쉼표가_값을_자르면_모르는_키로_잡는다`, `scripts/handout_exploded/build.py::PART_KEYS`.
