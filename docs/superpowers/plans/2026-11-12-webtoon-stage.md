# 초중등 교육자료 — 웹툰 칸 연출(aimotion 157) 01·02 시안 (구현 계획)

2026-11-12. 근거: `docs/handoff/2026-11-10-frontier-ai-transition.md` §7.1~§7.3 · `docs/handoff/2026-11-12-after-elevenlabs-subscription.md` A8.
범위는 **01·02 큐 시안까지**다. 19큐 확장은 사용자가 시안을 본 뒤 정한다(기존 합의).

## 무엇을 가져오나 — 기술 한 문장(소재 빼고)

"세로로 이어진 칸 스트립을 스크롤 위치 하나로 시간처럼 흘리고, 칸에 머무는 시간과 칸 사이 여백(쉼)을 속도장 위의 읽기 시간
σ(s)=∫ds/v 로 묶어 최소 저크로 움직이며, 칸은 다각형 clip 창이고 층마다 시차 f 가 다르며, 가장 센 박자는 테두리 위 층에 그려
여러 칸의 합집합으로만 잘라 테두리를 깨고 나온다."

가져오지 않는 것: 고양이·옥상·나비·노을 팔레트·회차 제목·"휙/쏙" 같은 데모 문구·9:16 형식·데모의 칸 좌표·연출 순서.
데모 코드(`strip.js` 속도장·σ 표·역함수, `main.js` 합집합 clip·집중선, `art.js` 말풍선 꼬리 식)는 **원리를 다시 썼다** — 옮긴 식이
있는 함수 옆에 MIT 고지(`© 2026 kstost, cokacmotion`)를 단다.

## 데모 → 이 공연 (§7.3 표를 구체화)

| 데모 | 여기서 |
|---|---|
| 칸에 머무는 시간 = 읽을거리(음절×0.06초) | **실제 음성 길이.** 칸 하나 = 한 사람이 이어 말하는 문장 묶음. 칸의 머무는 구간 = 그 문장들의 캐시 음성 시작~끝 |
| 여백 높이 = 쉼 × 520 (쓰는 순서는 거꾸로) | **빌더가 칸 경계 종류마다 쉼을 정해 음성 사이에 넣고**, 화면은 그 쉼 안에 이동이 꼭 끝나도록 여백 높이를 이분 탐색으로 푼다. 같은 사람 칸 나눔 = 문장 사이 쉼(GAP_SENT 0.16초 — 여백 최소, 이동은 앞 문장 끝을 0.5초쯤 앞당겨 출발) < 질문→답 0.95초 < 턴 경계(답→다음 질문) 1.25초 < 침묵 칸 앞 1.5초 — 레일에서 여백 리듬이 그대로 보인다 |
| 칸 모양의 언어 | 콘티 `kind`: 오프닝 `wide`(넓은 설정 칸) · 사회자 질문 `band`(가로 띠, 말풍선 왼쪽·그림 오른쪽) · 도슨트 핵심 `slant`(기울어진 칸 — 데모와 반대로 기울임) · `silent`(작은 침묵 칸, 말 없음) · 마지막 `free`(테두리 없는 칸, 종이에서 피어남) · 나머지 `normal` |
| 칸 깨기(테두리 위 층 + 합집합 clip) | 큐마다 한 번. 01 = 진흥원 안테나에서 나간 전파 띠가 기울어진 칸을 뚫고 여백을 건너 침묵 칸의 마을에 닿는다. 02 = 송신 안테나의 모스 신호(점·선)가 기울어진 칸을 뚫고 **여백 = 넓은 바다**를 건너 침묵 칸의 수신 안테나에 닿는다(여백 위에 카드의 경로 글) |
| 카메라 공간 연출 S(p)+s(t) | 깨고 나오는 물체를 화면 공간 베지어로 두고 스크롤을 더한다 — 여백이 물체 밑으로 지나간다. 도착하면 카메라 항을 얼린다 |
| 칸 안 층 시차 y − f·d | 칸마다 하늘·먼 배경·가까운 소품 층을 굽고 f 만 준다. 멈춘 순간(d=0)은 구운 구도 그대로 |
| 말풍선(타원+꼬리, 꼬리 뿌리에서 자람) | 풍선 모양만 캔버스(초타원 + 꼬리 + 같은 사람 풍선끼리 목으로 잇기, 외곽선 먼저 → 채움 나중). **글자는 DOM** — 말한 부분은 진하게, 남은 부분은 흐리게. 꼬리는 칸 밖, 말하는 로봇 쪽(사회자 왼쪽·도슨트 오른쪽)을 가리킨다 |
| 오른쪽 레일 | 스트립 지도(칸 = 덩어리, 말하는 사람 색), 여백 = 빈칸, 보는 창 |

## 구조

```
docs/design/handout-hud.html(검증된 카드·대사) ─┐
cache-elevenlabs/index.json + {키}.pcm ─────────┼─► build.py ─► docs/design/webtoon-stage.html (한 파일, 외부 리소스 0)
scripts/handout_webtoon/storyboard.yaml(콘티) ──┘      │  · 큐시트 순으로 문장 정렬·대조(다르면 멈춤)
                                                       │  · 콘티가 모든 문장을 순서대로 한 번씩 덮는지 검사(아니면 멈춤)
                                                       │  · 칸 경계 종류별 쉼을 넣어 이어 붙임 → mp3(40 kbps) data URI
template.html(엔진) + scenes.js(칸 그림) ──────────────┘  · 칸마다 t0·t1, 침묵 칸 시각, 수준 2개 × 큐 2개
```

- **콘티 = 데이터**(`storyboard.yaml`): 큐·수준마다 칸 목록 `{u: 발화, n: 문장 수, kind, art, brk?, v?}`. 대본이 바뀌어 문장 수가 어긋나면
  빌더가 어느 발화의 어느 문장인지 찍고 멈춘다.
- **한 HTML 에서 초등/중고등**: 위 막대의 [초등|중고등] 버튼, `?lv=초등|중고등`. 대사·카드·그림 유형이 수준마다 다르고, 칸 그림의
  이름표는 그 수준 카드(`items[].t`·`visual`)에서 읽는다 — 그래서 같은 그림 함수가 두 수준을 모두 그린다.
- **화면**: 1600×900 무대(창에 맞춰 축소). 가운데 세로 스트립 열(640) + 레일, 왼쪽 = 큐 꼬리표·사회자 로봇·제목·기억해 두기,
  오른쪽 = 도슨트 로봇·포인트 카드(도슨트가 그 포인트를 말하기 시작할 때 놓임).
- **진입점**: `?cue=01|02` · `?lv=초등|중고등` · `?t=초`(한 순간 멈춤) · `?check=1`(두 수준 × 두 큐를 모두 지어 `body[data-warn]` 에
  '대사에 없는 낱말'·'초등 숫자' 경고, `body[data-issues]` 에 배치 문제(칸 넘침·풍선과 이름표 겹침)를 적는다).
- **결정성**: 그림은 t 의 순수 함수(σ 표·여백 풀이는 장면을 지을 때 한 번). `Math.random`·`Date`·CSS transition 을 쓰지 않는다.
- **오프라인**: 글꼴은 시스템 글꼴(-apple-system·Apple SD Gothic Neo·Noto Sans KR·Malgun Gothic). 웹 글꼴 내장은 하지 않는다
  (데모의 Gaegu·Black Han Sans 는 손글씨 느낌용이었다 — 여기서는 글자가 대사·카드라 읽기 쉬운 고딕이 맞다).
- **색**: HUD 토큰(ink #0E2433 · 파랑 #0B7FB5 · 청록 #0A6F84 · 호박 #B96F00 · 사회자 풍선 #DDF1F5 · 도슨트 풍선 #FFEFD6).

## 배포 가능성

교육자료는 PC(전시장 화면)에서 여는 정적 HTML 이다. 로봇·데몬·프록시와 무관하고, 음성은 이미 구운 캐시를 읽기만 한다
(새 합성·외부 호출 0). 캐시 폴더는 `TTS_CACHE_DIR`(기본 `$TTS_ASSETS/cache-elevenlabs`). 색인 `engine` 이 elevenlabs 가 아니면
경고를 찍고 계속한다(Qwen 캐시로 시안을 만드는 것은 허용 — 실패는 소리 내서).

## 공연 모드(`?live`) — 조율자 추가 요구(2026-11-12 `LIVE-contract.md`) 반영

- **장면 시계는 `clock()` 하나**: 미리보기 = 이 페이지가 트는 캐시 음성의 `currentTime`, `?t=` = 고정, `?live` = `LiveFollow.time()`.
  장면·말풍선·낱말 시각(`sc.w`)·옆 열(카드·제목·기억해 두기)은 모두 이 값만 본다.
- **발화 표**: 큐마다 `utt: [{role, turn, t0, t1, s:[{x,t0,t1}]}]`, 턴 이름 `open / ask<i> / docent<i> / after`(종이 무대·`stage/say_label.py` 와 같음).
  LEAD 0.9 · GAP_SENT 0.16 · TAIL 1.6 은 종이 무대와 같다. **발화 안 문장 간격은 칸이 나뉘어도 GAP_SENT**(테스트로 고정) — 모듈이
  발화마다 앵커를 잡고 그 안은 캐시 PCM 시각 그대로 흐른다고 보기 때문이다. 발화 **사이** 쉼만 종이 무대(GAP_UTT 0.5)와 다르다(아래 '결정 필요').
- **공연 여부는 모듈이 정한다(`lf.enabled`)**: 감독 대시보드가 준 주소 `/stage/webtoon` 이면 기본 공연, `?preview` 면 미리보기, 파일로 열면 `?live` 일 때만.
  공연이면 Audio 를 만들지 않는다 · 재생/탐색 컨트롤(이전·장 고르기·다음·재생·막대·시간)을 `hidden` 으로 숨긴다 · 시작 덮개 없음 ·
  `html[data-live="1"]`. `scripts/handout_live/live_follow.js` 를 빌더가 인라인한다(없는데 `?live` 면 경고 + `data-live="missing"` + 위 막대에 '공연 모듈 없음').
- **수준**: 모듈에 `level: () => 지금 고른 수준` 과, 두 수준의 발화 표 중 **지금 고른 수준의 표를 돌려주는 얇은 껍데기**(`get utt()`)를 넘긴다.
  `onLevel(lv)` — 감독 수준이 초등·중고등이면 그 수준으로 스스로 바꾼다. 운영자가 직접 고른 수준(주소의 `lv`·수준 버튼)이 있으면 그쪽이 이긴다
  (10-01 계획 결정 3 — 모듈이 '수준이 다르다' 배지를 띄운다). 이 화면에 없는 수준(일반·전문가)이면 그대로 두고 배지로 알린다.
- **전역** `window.webtoonStage = { live, cue(), clock(), level(), audios(), getScene, draw, setCue }` — 종이 무대 `window.paperStage` 와 같은 모양.
  `onCue(i)` → 그 큐 장면을 짓고 띄운다.
  말하는 로봇 강조는 `speaking()` 으로, `phase()==='qa'` 면 장면을 멈춘다(생성 답의 글은 싣지 않는다 — 원래 안 싣는다).
- **쫓기**: 감독 시각이 앞으로 뛰면(실제 쉼이 콘티 쉼보다 짧아 다음 발화가 일찍 시작) 빠르기 `1 + 차이/1초` 로 쫓아간다. 그대로 따라가면 칸 이동
  (여백 = 쉼 구간)이 통째로 건너뛰어져 칸이 순간이동한다. 첫 동기화·새 큐·수준 전환·4초 넘는 도약은 바로 맞춘다. 지수 접근은 쓰지 않는다
  (말하는 동안 목표가 초당 1씩 움직이면 시정수만큼 늘 뒤처진다). 간격 dt 는 자르지 않는다(오래 못 그렸으면 바로 따라잡는다).

## 조율자에게

**공용 문서(`docs/lessons.md`)에 넣을 것** — 증상 → 원인 → 규칙
1. *한 경로에 겹친 도형을 넣고 `fill()` 하면 겹친 곳이 구멍이 될 수 있다.* 증상: 웹툰 말풍선 '목'의 외곽선이 풍선 글 위로 비쳤다.
   원인: 초타원(시계 방향)과 목 사각형(반대 방향)을 한 경로에 넣어 nonzero 감김 합이 0. 규칙: 외곽선 먼저·채움 나중으로 실루엣을 합칠 때는
   조각마다 따로 `beginPath/fill`, 이음 조각의 끝은 두 도형 **안쪽**에 둔다. (테스트로 고정 못 함 — 헤드리스 캡처로 확인)
2. *카드 i 를 도슨트 i턴에 묶으면 틀린다 — 턴 번호와 포인트 번호는 같지 않다.* 증상: 웹툰 02 중고등, 도슨트 0턴(발명·발견 도입)에 '1 맥스웰 · 예언'.
   규칙: 카드가 놓이는 시점은 그 포인트를 실제로 말하는 칸/문장에 묶는다(웹툰은 콘티 `card`/`item`). **종이 무대도 같은 방식**
   (`scripts/handout_paper/template.html` `common()` 의 `at: sc.at('docent' + i)`)이라 02 일반에서 같은 어긋남이 있을 수 있다 — 확인 필요(내 소유 아님).
3. *발화 안에 화면용 쉼을 넣으면 공연 모드에서 로봇보다 늦는다.* LiveFollow 는 발화마다 앵커를 잡고 그 안은 캐시 PCM 시각 그대로 흐른다고 본다.
   웹툰이 같은 발화의 칸 나눔에 0.7초를 넣었더니 칸 하나에 0.5초씩 늦었다. 규칙: 발화 안 문장 간격은 GAP_SENT 로 고정, 화면 연출은 발화 **사이**에서만.
   테스트: `tests/test_handout_webtoon.py::test_쉼은_경계_종류마다_다르고_발화_안은_GAP_SENT_다`.
