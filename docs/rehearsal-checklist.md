# 실기 리허설 점검표

로봇 두 대(사회자·도슨트)를 실제로 켜고 공연 한 벌을 돌리며 **테스트로만 확인한 것**을 실물로 확인한다.
계획 `docs/superpowers/plans/2026-11-14-show-readiness.md` A-4(P0-5). 항목마다 **하는 법 → 보이는 것 → 로그에서 볼 줄 → 통과/실패**.
"로그에서 볼 줄" 은 코드의 문구를 그대로 옮겼다(2026-11-14 기준) — 문구가 다르게 찍히면 그것도 실패로 적는다(코드가 바뀐 것이다).

로그 읽는 법: `./reachy.sh logs` — 감독(`.demo-logs/start-director.log`, 마지막 세션)·게이트웨이·TTS 프록시 경고를 한 번에.
로봇 앱 로그는 `REACHY_ROBOT_HOST=<주소> ./reachy.sh robot logs`. 조정실 '고급' 서랍의 이벤트 로그는 관람객 말을 `관람객> …` 으로 보인다.

## 1. 이번 계획의 새 항목

### 1-1. 외부 API 사전 점검(A-1) — 빨간 줄
- **하는 법**: (a) 평소대로 띄운다. (b) 한 번은 `.env` 의 `OPENAI_API_KEY` 를 일부러 틀린 값으로 바꿔 띄운다(끝나면 되돌린다).
- **보이는 것**: (a) 예열 줄 `LLM  프리픽스 캐시  …s` · `TTS  크레딧 남음 N / 131,000`. (b) 빨간 `FAIL` 묶음이 예열 직후와 **감독 콘솔 바로 위**
  에 한 번씩. 그래도 감독은 뜬다(멈추지 않는다 — U1 ①).
- **로그에서 볼 줄**: 화면 `   LLM  프리픽스 캐시 점검 실패 — OpenAI 키가 틀렸거나 만료(401): .env 의 OPENAI_API_KEY 를 확인한다`,
  감독 로그 머리 `사전 점검 실패: LLM(OpenAI) 점검 실패 — …`, `openai-gateway.log` 에 `OpenAI LLM(…) 실패 — 외부 전용이라 넘길 로컬 LLM 이 없다, 502`.
- **추가 확인**: 화면·로그 어디에도 키 조각이 없다 — `grep -c "sk-" .demo-logs/*.log` 의 새 줄이 0.
- 통과 ☐ 실패 ☐ 메모:

### 1-2. 사과문 두 번(A-2)
- **하는 법**: 공연 중 질문 창에서 PC 의 인터넷(유선·Wi-Fi 모두)을 끊고 질문을 **두 번** 한다. 끝나면 다시 잇는다.
- **보이는 것**: 두 번 다 도슨트 목소리로 "죄송합니다, 지금은 답을 찾지 못했습니다. 다음으로 넘어가 볼까요?". 대본(고정 대사)은 끊김 없이 이어진다.
- **로그에서 볼 줄**: 감독 `[<큐>:qa] LLM 생성 실패(…) — 폴백`, `tts-proxy.log` 에 사과문 두 문장의 `hit sohee '죄송합니다, 지금은 답을 찾지 못했습니다.'`
  · `hit sohee '다음으로 넘어가 볼까요?'`(`miss …` 나 `ElevenLabs 실패 — …` 가 아니다). 사과문은 굽기 목록에 있어야 한다 — 굽기 현황(§0)에서 빠진 것 0.
- **알려진 한계**: 1인 모드 + 인터넷 끊김이면 남은 로봇이 자기 목소리로 읽어 캐시가 빗나간다 → 사과문이 안내 한 번 뒤 무음(설계상 — 1인 모드 조합은 굽지 않는다).
- 통과 ☐ 실패 ☐ 메모:

### 1-3. 20분 방치 뒤 화면(A-3)
- **하는 법**: 감독이 뜬 채 키보드·마우스를 20분 건드리지 않는다(`pmset -g | grep displaysleep` 값보다 길게).
- **보이는 것**: 조정실·프로젝터 화면이 켜져 있다. 기동 출력에 `OK   공연 동안 화면·시스템 잠자기를 막는다`.
- **로그에서 볼 줄**: `pmset -g assertions | grep -A2 caffeinate` 에 `PreventUserIdleDisplaySleep named: "caffeinate command-line tool"` —
  감독을 끈(q) 뒤에는 그 pid 의 줄이 없다.
- 통과 ☐ 실패 ☐ 메모:

### 1-4. 짧은 추임새에 되묻기(A-5)
- **하는 법**: 질문 창에서 차례로 — "와 신기하다" → (되묻기 뒤) 바로 "대박" → (답 뒤) "전파가 뭐예요" → "5G 가 몸에 해롭다던데요".
  아이 목소리·작은 소리로 "라디오는요"(물음표 없이 들릴 만한 말)도 한 번.
- **보이는 것**: "와 신기하다" 에는 도슨트 답 없이 사회자가 "궁금한 점이 있으면 편하게 물어봐 주세요. 이어가려면 '다음'이라고 해 주세요."
  곧바로 이어진 "대박" 에는 **답한다**(연달아 두 번째). 질문·평서형 긴 말·"라디오는요" 에는 확인 멘트 + 도슨트 답.
  되묻기 뒤에도 침묵 대기(20초)가 다시 흐른다.
- **로그에서 볼 줄**: 감독 `질문으로 보지 않고 되묻는다: '와 신기하다' (연달아 한 번 더 말하면 답한다 · 끄기 REACHY_QA_REPROMPT=0)`.
  답한 말은 감독 로그에 `관람객 질문: '대박'`·`관람객 질문: '전파가 뭐예요?'` 처럼 한 줄씩 남는다(글만 — 조정실 경고로는 안 간다.
  단독 모드 답은 `관람객 질문(단독): '…'`).
  리허설이 끝나면 두 종류를 모아 **문턱을 다시 잰다** — 되물은 말에 진짜 질문이 섞였는지, 답한 말에 되물어도 될 잡담이 많은지.
  마지막 세션만 뽑기(줄 앞에 `무대감독> ` 이 붙을 수 있어 `-o` 로 자른다):
  `awk '/════════ 세션 시작/{b=""} {b=b $0 "\n"} END{printf "%s", b}' .demo-logs/start-director.log | grep -oE "관람객 질문(\(단독\))?: .*|되묻는다: .*"`
  고칠 곳은 `stage/cues.py::REPROMPT_MAX_CHARS`·`_REQUEST_WORDS`·`_ASK_ENDINGS`(측정 표는 `docs/superpowers/plans/2026-11-14-show-readiness-A.md` A-5).
  되묻기를 끄려면 `REACHY_QA_REPROMPT=0 ./run-app.sh`(명령 앞에).
- 통과 ☐ 실패 ☐ 메모(되물은 말 목록):

### 1-5. 로봇 주소 찾기(A-6) — 지금까지는 가짜 핑·가짜 조회로만 확인됨
- **하는 법**: (a) 두 로봇을 평소 주소로 켠 채, 사회자 주소만 없는 주소로 줘서 띄운다 —
  `REACHY_MC_HOST=192.168.0.99 REACHY_DOCENT_HOST=192.168.0.5 ./reachy.sh start --robot`(끝나면 `q`).
  (b) 두 로봇을 끄고 **도슨트 → 사회자** 순서로 켠 뒤 `ping -c1 reachy-mini.local`·`ping -c1 reachy-mini-2.local` 의 주소를 적고,
  **사회자 → 도슨트** 순서로 다시 켜서 또 적는다(`-2` 가 켠 순서로 바뀌는지 — U4 ③ hostname 바꾸기의 근거).
- **보이는 것**: (a) 사회자 자리를 건너뛰며 이름으로 찾아 알린다 — 감독은 그대로 1인 모드로 뜬다(**찾은 주소를 자동으로 쓰지 않는다**).
- **로그에서 볼 줄**: `   사회자 로봇을 이름으로 찾아본다(reachy-mini.local · reachy-mini-2.local) — 찾아도 자동으로 쓰지 않는다` →
  `WARN 사회자 로봇이 192.168.0.99 에 없다 — 192.168.0.4(reachy-mini-2.local)에서 찾았다(config 배역 mc). 그 주소로 띄우려면:` +
  `      REACHY_MC_HOST=192.168.0.4 REACHY_DOCENT_HOST=192.168.0.5 ./reachy.sh start --robot`,
  상대 로봇은 `   192.168.0.5(reachy-mini.local) 는 config 배역 docent — 사회자가 아니다`.
  config 를 못 읽으면 `WARN <주소>(<이름>)에 로봇이 있다 — 배역 미확인(config 를 못 읽었다). 이름으로 추측하지 않는다 — 확인: ssh pollen@<주소> cat …`
  (새 주소는 ssh 호스트 키가 없어 이렇게 될 수 있다 — `ssh pollen@<주소>` 로 한 번 붙어 키를 받아 둔다).
- (b) 결과: 도슨트 먼저 → reachy-mini = , reachy-mini-2 = / 사회자 먼저 → reachy-mini = , reachy-mini-2 =
- 통과 ☐ 실패 ☐ 메모:

### 1-6. 수준별 화면 — 하이라이트 끝까지(C·D)
- **하는 법**: 코스 하이라이트(`k 하이라이트`)로 초등 한 바퀴, 전문가 한 바퀴(질문 한 번씩 포함).

## 2. 11-13 에 바꾼 9가지 — 지금은 테스트로만 확인됨

### ① 질의응답 흐름(받아치기 → 질문 → 확인 멘트 → 도슨트 답 → 재질문)
- **하는 법**: 받아치기("…이어가려면 '다음'이라고 해 주세요.")가 끝나면 사회자 로봇 앞에서 "전파는 어떻게 멀리 가요?" 라고 묻는다.
- **보이는 것**: 사회자 확인 멘트(예: "좋은 질문이네요. 도슨트, 답해 줄래요?") → 도슨트 답 → 사회자 재질문("궁금한 점 있으실까요? 이어가려면 '다음'이라고 해 주세요.").
- **로그에서 볼 줄**: 조정실 이벤트 `관람객> 전파는 어떻게 멀리 가요?`, 로봇(사회자) 앱 `나(STT +…s)> …`. 감독 로그에는 질문 글이 남지 않는다
  (다른 섹션 근거를 실을 때만 `[<큐>:qa] 질문이 '<큐>' 섹션과 더 가깝다 — 그 근거도 싣는다`). 실패면 `[<큐>:qa] LLM 생성 실패(…) — 폴백`.
- 통과 ☐ 실패 ☐ 메모:

### ② 답 분량(§15.15 — 수준별 문장·글자 수)
- **하는 법**: 같은 질문을 초등·일반·전문가에서 한 번씩(조정실 수준 버튼 또는 `l <수준>`).
- **보이는 것**: 초등 3~4문장 · 중고등 3~5 · 일반 4~5 · 전문가 4~6. 사회자 확인 멘트(약 3초)가 끝날 때 답이 바로 이어진다.
- **로그에서 볼 줄**: 감독 머리 `관람객 수준: 일반 (기본값) — 질문 답 4~5문장 / 150~260자`(값은 `data/levels.yaml`), 너무 짧으면 짧다는 경고.
- 통과 ☐ 실패 ☐ 메모:

### ③ "다음"·"이어서 진행" 인식
- **하는 법**: 질문 창에서 "다음", "이어서 진행해 주세요", "계속" 을 각각 말한다(짧게, 보통 목소리). 아이 목소리가 있으면 한 번.
- **보이는 것**: 바로 다음 큐로 넘어간다. "이어서 설명해 주세요" 는 **질문**으로 받아야 한다(넘어가면 실패).
- **로그에서 볼 줄**: 조정실 `관람객> 다음` 뒤 다음 큐의 사회자 say. 마지막 큐에서는 `마지막 큐다 — 더 진행할 곳이 없다`.
- 통과 ☐ 실패 ☐ 메모(인식 못 한 말과 실제 전사):

### ④ 조정실 안 시연 화면(수준 바꾸면 그 자리에서 바뀜)
- **하는 법**: 공연 중 조정실에서 수준을 일반 → 초등 → 전문가로 바꾼다.
- **보이는 것**: 조정실 안 시연 화면이 그 자리에서 갈아 끼워지고(빈 화면 없음) 머리 줄이 바뀐다. 프로젝터 창(`/stage/auto`)도 같이.
- **로그에서 볼 줄**: 감독 `관람객 수준 … → … — 바로 적용(지금 문장은 끝까지, 다음 발화부터)`.
- 통과 ☐ 실패 ☐ 메모:

### ⑤ 1인 모드 띠·합류 명령
- **하는 법**: 도슨트 로봇 앱만 끈 채(또는 전원 끈 채) [공연 시작] → 한두 큐 뒤 공연 종료(e) → 감독 창의 합류 명령으로 도슨트를 붙이고 다시 시작.
- **보이는 것**: 조정실 위 띠 "1인 모드 — 도슨트 로봇이 없어 사회자 로봇이 도슨트 대사도 자기 목소리로 읽는다. …". 합류 뒤 띠가 사라진다.
- **로그에서 볼 줄**: 감독 `━━ 1인 모드로 시작한다 — 도슨트 로봇이 없어 사회자 로봇이 도슨트 대사도 자기 목소리로 읽는다. 두 대로 하려면 공연 종료(e) → 도슨트 로봇을 붙인 뒤(REACHY_ROLE=docent REACHY_ROBOT_HOST=<주소> ./reachy.sh robot up) 다시 시작 ━━`
  — **주소가 들어 있어야 한다**(없으면 실패: 기본 주소로 가서 다른 로봇 config 를 덮어쓴다).
- 통과 ☐ 실패 ☐ 메모:

### ⑥ `clean-local`
- **하는 법**: 로컬 구성으로 한 번 띄웠다 끈 뒤 `./run-app.sh` 로 외부 전용 기동(자동으로 부른다). 따로 보려면 `./reachy.sh clean-local --robot --dry-run`.
- **보이는 것**: 내릴 것만 내리고 외부 전용으로 뜬다. 감독이 떠 있으면 아무것도 안 내리고 멈춘다.
- **로그에서 볼 줄**: `   내린다: …` / `   남긴다: OpenAI 게이트웨이(:8080·:8090) — 같은 설정(외부 전용)` / `   내릴 것이 없다`.
- 통과 ☐ 실패 ☐ 메모:

### ⑦ Wi-Fi 절전 끄기
- **하는 법**: 로봇을 재부팅한 뒤(절전이 다시 켜진다) 기동한다.
- **보이는 것·로그**: 로봇마다 `OK   Wi-Fi 절전 끔 (<주소>) — 켜져 있으면 첫 패킷이 늦거나 빠져 로봇이 안 잡힌 것처럼 보인다`.
  로봇에서 `iw dev wlan0 get power_save` → `Power save: off`.
