## 게이트웨이 번역 목록 — 실측으로 확인한 것

로봇(`apps/voice_chat/voice_chat/llm.py::LLMClient`)은 `{"model":"local", messages, stream:true, temperature:0.7, max_tokens}` 를 보낸다. 측정 도구의 `Gateway` 클래스가 한 번역이 곧 목록이다.

| # | 번역 | 안 하면 | 근거 |
|---|---|---|---|
| 1 | `max_tokens` → **`max_completion_tokens`** | **400** `Unsupported parameter: 'max_tokens' is not supported with this model` — luna·terra·sol 모두 | `llm/preflight.json` |
| 2 | `model: "local"` → 실제 모델 이름 | OpenAI 에 없는 이름(따로 재지는 않았다) | — |
| 3 | `reasoning_effort: "none"` **반드시** 넣기 | 기본값이 `medium` 이라 사고한다(11-10 문서: 5초대) | 모델 페이지·reasoning 가이드 |
| 4 | `temperature 0.7` 은 luna·terra 는 그대로 받는다. **6.1-sol 은 거절**(400 `Only the default (1) value is supported`) | sol 을 쓰면 빼야 한다 | `llm/preflight.json` |
| 5 | 사용량을 받으려고 `stream_options.include_usage` 를 켜면 마지막에 **`choices: []` 청크**가 온다 — 로봇 `LLMClient` 는 `["choices"][0]` 을 바로 읽어 IndexError 로 **생성 전체가 실패**한다 | 게이트웨이에서 걸러서 넘긴다(켜지 않거나) | 측정 도구 `_Stream` |
| 6 | 로봇의 읽기 타임아웃은 10초(`LLMClient.timeout`) — OpenAI 첫 글자가 7.9초까지 간 구간이 있었다. **첫 글자 5초 초과: luna 4/128(전부 흔들림 구간), sol 1/32, 나머지 0/128** — B2 의 LLM 기한 5초면 이 몫이 실패 경로로 간다 | 10초를 넘으면 감독이 큐시트 폴백으로 간다 | 아래 「지연」 |
| 7 | 연결 재사용은 큰 차이가 없다(매번 새 연결: 첫 글자 중앙 0.94초 vs 재사용 0.96초) | — | `jitter` 측정 |

STT 번역(실측):

| # | 번역 | 안 하면 |
|---|---|---|
| S1 | 로봇의 `language=auto`(또는 `ko`) → **`languages` 를 반드시 채운다** — `["ko"]` 가 가장 낫고, `["ko","en"]`(B2 `languages_for` 의 auto 처리)도 거의 같다(성인 1.2% vs 0.9%, 짧은 말 같음). `language` 는 보내지 않는다(둘 다 보내면 거절 — STT 가이드) | **비우면** 짧은 말의 언어 오판 — "다음" → `Palum.`/`タム。`, 짧은 말 CER 24% |

| S5 | 비용 계산은 요청당 초 올림 | 오디오 길이로 계산하면 14% 적게 잡힌다 |

## 방법

### LLM
- **앱 경로 그대로.** 지시문은 실제 큐시트(`data/cues.yaml`)로 띄운 `Director._answer()` 가 만든 것을 생성 콜백에서 가로챘다(근거·금지 규칙·초등/중고등의 참고 사실·관련 섹션까지 앱과 같다). 생성은 `stage.__main__.build_generate(level)` 를 그대로 불렀다 — 시스템 프롬프트(`build_system_prompt("docent", level)`), 이력 변환, 요청 본문(`LLMClient`), 후처리(이름표 → 분량 상한 → 글 표기 → 글말 경고)가 모두 앱 코드다. 바꾼 것은 `llm._session` 하나 — 측정 도구 안의 가짜 게이트웨이가 주소를 돌리고 OpenAI 면 키·모델·`reasoning_effort` 를 넣고 위 번역 1을 했다.
- 이력: 질문 창이 열리기까지 그 큐의 고정 대사(사회자 오프닝·턴 질문·도슨트 설명·받아치기)를 `_remember` 로 쌓았다. 실제 공연은 앞 큐 대사도 12줄까지 남는다(근사).
- 질문 32개 × 4수준 = 128건씩. 질문마다 모델 순서를 섞었다. 수준마다 예열 호출(로컬 3회 — 슬롯 3개, OpenAI 1회)은 통계에서 뺐고, **예열에 쓴 q01 은 지연 통계에서 뺐다**(로컬 첫 글자 0.03초 — 캐시가 통째로 맞는다).
- 로컬: `llamactl reach-llm` 과 같은 옵션(`gemma-4-E4B-it Q4_K_M`, `-ngl 99 --ctx-size 24576 --parallel 3 --no-kv-unified --reasoning off`)으로 임시 포트 18080 에 단독 기동, 끝나고 껐다. 측정 PC 는 이 맥(Apple Silicon, 한국 회선).
- 규칙 검사는 저장소 함수 그대로: 분량 상한(`cap_length`), 하한(감독 `_warn_if_short` 와 같은 `level.min_chars`), 이름표, 글 표기(`speakable`), 글말(`written_endings`). 수준 숫자 규칙은 교육자료 검증기(`scripts/handout_hud/cards.py`)의 초등 판정(아라비아 숫자)과 같고, **관람객이 질문에서 말한 숫자("5G", "1세대")는 뺐다**. 근거 밖 숫자 = 답의 숫자 ⊄ 지시문+이력+질문의 숫자(원문자 ④·앞자리 0 은 맞춘다).

### STT
- **시험 세트**: 관람객 질문 24개(LLM 질문에서 고름) + 공연의 짧은 말 6개("네"·"다음"·"아니요"·"감사합니다"·"안녕하세요"·"한 번 더 말해 주세요") × ElevenLabs 라이브러리 한국어 목소리 6개(여·젊음 Aria, 남·젊음 캐릭터 Deoksu, 남·젊음 Taek, 여·중년·약한 지역 억양 Shin rara, 남·노년 Sung-ho, 여·노년 MJay) — `eleven_v4_turbo`.
- **아이 근사 2개**: Aria +4반음, Deoksu +5반음 — 음높이와 포먼트를 함께 올렸다(위상 보코더로 늘인 뒤 재표본화, 길이 유지). 아이 음성 인식 연구의 증강 기법이지만 진짜 아이의 조음·억양은 없다.
- **로봇 입력과 맞춤**: 24 kHz → 16 kHz 모노 16-bit(앱 `stt.transcribe` 와 같은 WAV 조립), 앞뒤 무음 0.3초, 음성 RMS -23 dBFS. 조건 두 가지 — 깨끗함 · 분홍 잡음 SNR 15 dB. 말 없는 조각 5개(잡음 1.5·3·5초, 거의 무음 2·4초). 모두 485조각, 22.4분.
- **비교 6가지**: 로컬 `stt_server.py`(임시 포트 18090, 같은 모델) `language=auto`(**앱 기본값**)·`ko` · `gpt-transcribe` `languages` 없음·`languages[]=ko`·`[ko, en]`(B2 게이트웨이가 auto 를 이렇게 보낸다 — 나중에 추가로 잼)·`languages[]=ko` + `keywords[]`(전시 고유명사 16개 — 마르코니·헤르츠·타이타닉·테레민·크로마키 등). OpenAI 는 3개씩 동시에 보냈고 지연은 요청마다 쟀다.
- **채점**: CER = 글자 편집 거리 ÷ 정답 길이, 띄어쓰기·문장부호 무시, 숫자·단위는 읽는 소리로 편 뒤(`scripts/tts_review.py::spoken`·`norm`). 발음 CER 은 같은 파일의 `phonetic`(연음·받침 규칙 적용 자모열).

발음 CER(소리 기준)은 전부 이보다 낮다 — 원시 표는 `stt/summary.md`.

- **`languages` 없이 보내면 쓸 수 없다.** 짧은 말에서 언어를 잘못 고른다 — "다음" 이 8목소리 중 5개에서 `Palum.`·`Thaum.`·`Taum.`·`Home.`(감지 en)·`さん。`(감지 ja)이 됐다. 감독의 진행 키워드("다음")가 통째로 안 먹는다. **게이트웨이는 로봇이 `language=auto` 를 보내도 `languages[]=ko` 로 고정**해야 한다(영어 질문을 받을 일이 생기면 그때 `["ko","en"]` 를 따로 잰다).
- **`ko` 로 고정하면 성인은 OpenAI 가 낫고(0.9% vs 1.5%) 아이 근사는 로컬이 낫다(3.0% vs 5.6%, 잡음 6.6% vs 9.0%).** 아이 목소리에서 OpenAI 가 틀린 것은 대부분 **전시 낱말**이다("전파" → "전편", "파장" → "화장"·"사장", "헤르츠" → "하르츠", "타이타닉" → "팔탄읍", "테레민" → "태닝", "장황남" → "장원남"). 음높이를 4반음 올린 여자아이 근사가 남자아이 근사보다 훨씬 나빴다(8.3% vs 3.0%).
- **keywords 가 그 차이를 뒤집는다.** 키워드가 든 문장 CER 3.6% → 0.2%, 키워드 없는 문장은 1.9% → 1.6%(나빠지지 않음), **없는 키워드를 끌어온 받아쓰기 0건/480**. 다만 이 키워드 16개는 시험 문장에서 뽑았다 — 실제 이득은 이보다 작다. 게이트웨이는 키워드를 큐시트(`data/cues.yaml`)의 고유명사에서 만들어야 실제 관람객 질문에도 걸린다.
- **로컬 `auto`(지금 앱 기본값)는 잡음 속 아이 목소리·짧은 말에서 언어 감지가 흔들린다**(11.6%·10.4% vs `ko` 6.6%·4.2%). 로컬을 계속 쓰더라도 `REACHY_STT_LANG=ko` 가 낫다(`stt.py` 주석의 권고와 같은 결과).
- "5G" 가 든 문장은 모든 OpenAI 설정에서 "파이브즈"·"파이브지" 로 적혔다 — ElevenLabs 가 "5G" 를 영어로 읽었을 가능성이 커서(합성 세트의 한계) 오류로 세지 않는 편이 맞다. 로컬은 "5G" 로 적어 0이 됐다.

### 지연(초, 요청~응답, 조각 평균 2.8초)

| 시스템 | 중앙 | p90 | 최대 |
|---|---|---|---|
| 로컬 `ko` | **0.22** | 0.24 | 1.17 |
| 로컬 `auto` | 0.39 | 0.41 | 3.60 |
| OpenAI(네 설정 합쳐 1,940회) | **0.73** | 0.89~0.92 | 3.12, 그리고 **27.4초 1건** |

- OpenAI 는 로컬보다 **0.35~0.5초 늦다.** STT 지연은 확인 멘트가 가려 주지 못한다 — 관람객 말이 끝나고 사회자가 반응하기까지의 침묵이 그만큼 길어진다(LLM 지연은 멘트가 가린다).
- **27.4초 1건**(1,940회 중 1회, 3초 조각, 결과는 정확): 앱의 STT 타임아웃은 15초이고 넘으면 `stt.transcribe` 가 **빈 문자열을 조용히** 돌려준다 — 관람객 질문이 침묵으로 처리된다. 게이트웨이는 OpenAI 호출에 짧은 타임아웃(예: 5초)과 1회 재시도를 두고, 실패하면 경고를 남겨야 한다.

### 비용
- 청구는 요청마다 **초 단위 올림**(응답 `usage: {type: duration, seconds}`) — 이 세트는 오디오 22.4분이 25.6분으로 청구됐다(+14%). 실효 단가 약 $0.0051/분.
- 회당: 관람객 말 3분이면 약 $0.015. 이 측정의 STT 전체 비용은 $0.46(4설정 × $0.115).

### STT 권장
**`gpt-transcribe` + `languages[]=ko` 고정 + 큐시트에서 만든 `keywords`** 를 기본으로 한다. 성인 오류율이 가장 낮고(0.1~1.6%), 잡음·무음에서 말을 지어내지 않으며, 아이 근사에서도 로컬보다 낫다(2.1% vs 3.0%) — 단 그 우위는 키워드 덕이고 키워드는 시험 문장에서 뽑았다. **아이 목소리는 아직 열린 위험**이다: 합성 근사로만 쟀고, 키워드 없이는 로컬에 졌다. 실기 리허설(A6)이나 체험관 현장에서 실제 아이 녹음 10~20개(보호자 동의)로 같은 도구를 한 번 더 돌려 확정한다. 로컬 STT 는 폴백으로 남긴다(게이트웨이 스위치, 로컬은 `ko` 로).

- **한 번씩만 쟀다.** 생성은 `temperature 0.7` 이라 같은 질문도 답이 바뀐다 — 위반 1~2건 차이는 우연일 수 있다.
- **지연은 하루 저녁(2026-11-12 21~22시) 한 회선이다.** OpenAI 쪽 흔들림 구간이 한 번 있었다. 전시장 회선·시간대에서 다시 재야 한다(실기 리허설 A6 에서 `tts-proxy.log` 와 함께).
- 로컬 Gemma 는 이 맥을 혼자 썼다. 실제 공연은 같은 맥에서 STT·TTS 프록시가 함께 돈다(로컬 지연은 실제보다 낙관적일 수 있다).
- 한국어 자연스러움은 기계로 채점하지 않았다(Claude 로 채점하지 않는다는 결정). 위 표본과 블라인드 나란히 표로 사람이 본다.
- **STT 음성은 합성이다**(STT 절). **아이 목소리는 근사다** — ElevenLabs 한국어 라이브러리에는 실제 아이 목소리가 없고, 목소리 디자인으로 아이 목소리를 만들면 403 `blocked_generation`(안전 정책)으로 막힌다.

.venv/bin/python scripts/measure_openai_llm.py --dry-run          # 질문 수·예상 비용(호출 없음)
