## 4. 알려진 한계 — 알고 그대로 둔 것

- **1인 모드 + 인터넷 끊김**: 남은 로봇 목소리로 말하므로 캐시 키가 빗나가 안내 한 번 뒤 무음이 된다(갈래 A).

- **시뮬은 두 목소리가 같은 스피커**: `REACHY_DOCENT_AUDIO_OUT` 로 가른다. 실기와 무관.
- **실기 카메라 패널(RTC)**: SDK 1.10 에서 WebRTC 협상 실패 중 — 조정실 카메라 칸은 '고급' 서랍 안에 접혀 있다(로봇 연결은 머리의 로봇 알약으로 본다).
