# 발표형 교육자료 (HUD 안)

전파체험관 19큐 전체의 교육자료를 **한 장짜리 HTML** 로 만든다. 큰 화면에 띄워 발표하는 용도다.

    open docs/design/handout-hud.html          # 만들어 둔 결과(생성물 — 직접 고치지 않는다)
    .venv/bin/python -m scripts.handout_hud.build   # 카드·대사를 고친 뒤 다시 만들기

## 화면 설계(사용자 요구, 2026-10-06)

1. **교육 자료는 화면 가득.** 제목은 가로 전체, 카드는 하단 전체. 창이 커지면 글자·간격이 같이 커진다.
2. **사회자는 콘텐츠의 왼쪽, 도슨트는 오른쪽 — 고정 구역**에 말풍선으로(하단이 아니다).
3. **HUD** — 말하는 문장 하나만(길면 쉼표에서 끊은 절), 반투명, 말한 부분은 진하게, 끝나면 흐려졌다 사라지고 아이콘만 남는다.
4. 로봇 아이콘은 사용자가 준 이미지(`scripts/handout_hud/reachy-mini-icon.png`, 흰 배경 투명화). 도슨트는 좌우 반전.

위 도구줄: 장 선택(‹ ›·목록·←/→)·수준(초등·중고등·일반·전문가)·코스(전체 19/하이라이트 9)·`▶ 시뮬레이션`(감독의 `say` 흐름을
흉내 — 말풍선·카드 강조·그림 연동). 02는 마르코니 대목에서 신호가 날고, 03은 다이얼이 돈다.

## 어디에 무엇이 있나

| 파일 | 역할 |
|---|---|
| `data/handout-cards/<큐>.yaml` | **카드**(제목·카드·기억해 두기·그림) — 큐 19개 × 4수준. 사람이 읽고 고친다 |
| `data/cues.yaml` | 말풍선에 흐르는 대사(로봇이 실제로 하는 말 그대로) |
| `scripts/handout_hud/cards.py` | 카드 **검증기** — 지어낸 말을 막는다 |
| `scripts/handout_hud/build.py` / `template.html` | 빌더와 틀. 카드가 검증을 못 넘으면 **만들지 않고 멈춘다** |
| `tests/test_handout_hud.py` | 검증기·빌더·브라우저(19장×4수준 넘침·겹침·시뮬레이션) |

## 카드를 쓰는 규칙(검증기가 강제한다)

카드는 **검수한 고정 대본을 줄여 쓴 것**이다. 새 사실을 들이지 않는다.

- 숫자·연도·영문 약어는 그 수준이 허용하는 글에 있어야 한다 — 초등·중고등: 실제로 **말하는** 대사만 / 일반: + 그 수준 브리프 /
  전문가: + 조사 자료 `facts`. 초등은 말하지 않은 숫자를 못 쓴다. 단위(km·Hz)는 예외.
- 글 겹침: 본문 ≥50%, 제목·기억해 두기 ≥30%(대본의 말을 줄여 쓴다). 길이 한도: 제목 32 · 카드 제목 18 · 카드 본문 90(목표 70) ·
  기억해 두기 46자.
- 카드 수 = 그 큐의 포인트 수(1~3). 그림은 `keyfact`(핵심 수치 1~3)·`steps`(단계 3~5) — 02는 `route`, 03은 `dial`(코드가 그린다).
- 근거 줄(전문가): `facts_used: [번호]` 로 이름을 자동 생성하거나 `source:` 로 적되 이름은 조사 자료에 **그대로** 있어야 한다.
- 수준별 `guard`(금지 규칙)와 조사 자료의 `corrections`·`unverifiable` 은 작성자가 지킨다 — 기계가 못 잡는 의미 검사다.

검사만: `.venv/bin/python -m scripts.handout_hud.cards [파일…]`

## 알고 있어야 할 것

- **검증기는 "지어내지 않았다" 를 보장하지 "맞다" 를 보장하지 않는다.** 카드는 사람이 한 번 읽어야 한다.
  작성 중 드러난 **대본의 모호한 곳**: 08 안테나 위치 전시물·이륙 절차는 현장 확인이 필요(`unverifiable`)해 카드에서 뺐다 /
  14 전문가 "그해 포니2" 는 조사 자료의 출시 연도와 안 맞아 "그해" 를 뺐다 / 10 전문가 그림의 등급별 출력(1kW·200W·100W·10W)은
  도슨트가 말하지 않고 브리프·조사 자료에만 있다 / 17 전문가 "실제 행성 탐사" 는 대본 그대로(정정이 달·행성 단정을 막는다).
- 지금은 **시뮬레이션 대본으로 움직인다.** 실제 감독의 `say` 에 연결하는 자리는 `window.hud`(`freeze`·`play`·`next`·`setSlide` …)이고
  `onSay` 는 아직 없다. `/handout`(`stage/handout.py`)은 그대로다 — 이 HTML 은 그 자리를 대신하지 않는다.
- 폰(세로)은 구역을 위아래로 쌓는 **임시 대체**다. 인쇄용 레이아웃은 없다.
