# 구현 스펙 설명 대본 (1분)

시연 직전 또는 직후에 읽는다. 실측값만 담았다 — 근거는 `docs/latency-m0.md`.
소리내어 읽으면 **약 55초**다. 표시된 쉼(`/`)에서 한 박자 쉰다.

---

## 대본

이 로봇은 **인터넷 없이** 동작합니다. /
음성 인식, 대화 생성, 음성 합성이 **전부 이 노트북 안에서** 돌아갑니다. /
발화 내용이 밖으로 나가지 않고, API 비용도 들지 않습니다.

구조는 넷으로 나뉩니다. /
말이 끝나면 **음성을 텍스트로** 바꾸고, /
**소형 언어모델**이 답을 만들고, /
그걸 **음성으로** 읽으면서, /
동시에 **감정 모션**을 재생합니다.

속도가 핵심이었습니다. /
말이 끝나고 **1초 안에 로봇이 반응**하고, /
**2초 안에 대답이 시작**됩니다. /
모션과 대답을 **따로 돌려서** 얻은 결과입니다. /
로봇은 여러분 말이 끝나자마자 반응하고, 대답은 그 뒤에 이어집니다.

확장은 **파일 하나씩**입니다. /
성격을 바꾸려면 프롬프트 파일, /
감정 표현을 늘리려면 모션 파일, /
클라우드 AI로 바꾸려면 **주소 한 줄**만 고칩니다.

실물 로봇으로 옮길 때도 **환경변수 세 개**만 바꿉니다. /
지금 검증한 것이 그대로 넘어갑니다.

## 숫자를 물으면 (예비 답변)

| 질문 | 답 |
|---|---|
| 얼마나 빠른가 | 발화 종료 후 모션 0.95초, 음성 응답 2.0~2.35초. AI 첫 응답은 0.09초 |
| 어떤 AI인가 | Gemma 4 E4B, 4비트 양자화. 노트북에서 도는 소형 모델 |
| 대화를 기억하나 | 최근 3턴. "아까 그거"가 통합니다 |
| 다른 언어는 | 한국어·영어·일본어·중국어. 말한 언어로 알아듣고 그 언어 음성으로 답합니다 |
| 개발 규모 | 앱 코드 875줄, 자동 테스트 47개 |
| 실물 이전 비용 | 앱은 로봇 본체에서 돌고 AI 연산만 PC가 맡습니다. 음성이 네트워크를 타지 않아 지연이 늘지 않습니다 |
| 지금 안 되는 것 | 로봇이 말하는 중에 끼어들기. 시뮬레이터에 하드웨어 에코 제거가 없어서인데, 실물에는 전용 칩이 있어 해소됩니다 |

## 읽을 때 주의

- **"소형 언어모델"** 을 강조한다 — 노트북에서 돈다는 게 핵심 메시지다.
- 속도 숫자는 **시연에서 방금 본 것**이라 말하면 설득력이 는다.
- 마지막 두 문단(확장·이전)이 투자 판단에 직결된다. 서두르지 않는다.
- 1분을 넘기면 잘라낼 순서: 구조 설명 → 숫자 → 확장. **확장과 이전은 남긴다.**
