## 대본을 고칠 때 지켜야 하는 것

### 1. 모델 이름 표기는 실측으로 고정됐다 — 임의로 바꾸지 말 것

serena 는 문자체계와 무관하게 읽지만 **영문 표기 형태에 따라 발음이 무너진다.**
아래는 전부 합성해서 ASR 로 되받아 확인한 결과다.

| 확정 형태 | 쓰면 깨지는 형태 |
|---|---|
| `Whisper Large V3 Turbo` | — |
| `Metal` | — |
| `Apple Silicon 칩에` | `Apple Silicon에` / `Apple Silicon 에` → '에폰/알퍼 실리콘'<br>`Apple 실리콘에` → 문장 전체 붕괴 |
| `Gemma E4B` | `Gemma four E4B` → 'ZAMA4'·'머폰'·'잼 마쏘' · `Gemma 4 E4B` → 'Xamasa'<br>**"four" 를 빼야 읽는다** — E4B 가 이미 4 를 담아 정보 손실은 없다 |
| `4-bit로` | `4비트로` → **'셋 비트' — 숫자가 틀린다.** 게다가 같은 문장 뒤의<br>`0.05초` 까지 '0.40여초' 로 오염된다 |
| `Alibaba 의 Qwen3-TTS 로` | `Qwen3-TTS` 단독 → '퀀퀀' · `Qwen 3 TTS` → '초이섬'<br>`Qwen three` → 'Fuse in' · `QwenTTS` → '펀티스' |

두 가지 규칙으로 요약된다.

- **아라비아 숫자를 한글·영문에 바로 붙이지 마라.** 값이 틀리고 인접 숫자까지
  오염된다. 단어로 쓰거나(`four`) 하이픈으로 끊는다(`4-bit`).
- **라틴 고유명사는 뒤에 한글 명사를 붙여 받쳐준다.** `Apple Silicon 칩에` 는
  되지만 `Apple Silicon에` 는 깨진다.

> ⚠ **Qwen 은 어떤 형태로도 깨끗하지 않다.** 확정 형태도 '알리바바의 QN3 TTS' 로
> 들린다(Alibaba 를 붙여 브랜드를 알아듣게 한 것이 최선). 음차
> `큐원 쓰리 티티에스` 가 오디오 자체는 더 정확했으니, 청취 후 되돌리려면
> 8번 문장만 바꾸면 된다.

### 3. 고친 뒤에는 F0 를 다시 재고 시드를 다시 고른다

합성은 결정적이라 같은 문장은 항상 같은 소리가 난다. 대신 문장에 따라 음높이가
평균에서 크게 벗어나 **목소리가 바뀐 것처럼 들린다.** `SEEDS` 는 그걸 잡는 장치다.

문장을 고쳤으면 seed 0~6 을 스윕해 고른다. 기준 순서는 ① **길이 이상치 배제**
② ASR 역전사 일치 ③ F0 가 대본 중앙값(284 Hz)에 가까움 이다.

> ⚠ **①이 가장 중요하다.** 1.7B 에서 고른 `11: 2` 를 0.6B 에 그대로 뒀더니 11번이
> 3.4초 → **10.07초로 늘고 환각 발화가 붙었다**("흥, 계곡 아대티에 떠나싸며…").
> 그 시드에서만 재현됐다. **시드는 모델에 종속된다 — 모델을 바꾸면 전부 다시 고른다.**

**F0 가 절대 기준은 아니다.** 6번은 F0 최적(무시드, Δ11)이 ASR 에서 '점어 4, E4, B'
로 끊겨 받혀, Δ26.7 이지만 '제마4 E4B' 로 깨끗한 seed=5 를 골랐다 — 모델명 전달이
그 문장의 목적이라 발음을 우선했다.

### 4. 문장을 짧게 유지한다

긴 입력에서 합성 길이가 크게 흔들린다. 절 단위로 따로 보내야 하며,
**여러 절을 합쳐 한 번에 보내면 TTS 서버가 죽는다**(`ee82b0d`).
